# CrediNoda - Paquete Principal de la Aplicación

Este directorio contiene el código fuente principal de **CrediNoda** (módulos de dominio, servicios de negocio, capa de persistencia SQLite, interfaz CustomTkinter y pruebas automatizadas).

Para consultar la **documentación completa del proyecto, qué problema resuelve y cómo utilizar la aplicación**, por favor consulta el archivo principal en la raíz:

👉 **[README Principal del Repositorio](../README.md)**

---

### Ejecución Rápida

Desde la raíz del repositorio (`CrediNoda`):

```bash
python -m credito_app.main
```

O para ejecutar la suite de pruebas automatizadas:

```bash
python -m pytest
```
